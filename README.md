Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

`main.py` (Python 3.13, standard library only, no network) writes one line —
the funniest one-line pickup line a robot could use — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
The program is deterministic: every run writes byte-identical output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
